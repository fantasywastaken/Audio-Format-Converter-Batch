Audio Format Converter Batch - A high-performance batch audio format converter written in Rust that wraps ffmpeg. Supports MP3, WAV, FLAC, OGG, M4A, and AAC formats. Convert whole music libraries in parallel with a fixed-size thread pool, live progress bar, per-file success and failure reporting, and clear error messages when ffmpeg is missing. Recursive directory scanning, configurable bitrate, optional overwrite protection, and dry-run preview mode. Cross-platform CLI tool for musicians, podcast producers, audio engineers, media archivists, and anyone who needs to bulk-transcode audio files fast. Keywords: audio, converter, ffmpeg, batch, mp3, wav, flac, ogg, m4a, aac, transcoder, cli, rust, parallel, music.
